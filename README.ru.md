# PAPIRO

**PAPIRO — разрабатываемая OSINT-платформа для исследования людей на основе общедоступной информации.** Долгосрочная цель проекта — автоматизировать максимально возможную часть процесса: собирать сведения из разных источников, обнаруживать и сопоставлять индикаторы, выявлять возможные идентичности и итеративно расширять исследования по мере появления новых данных, в том числе при работе с большими объемами информации.

Это направление развития проекта, а не описание текущего уровня автоматизации. Сейчас PAPIRO предоставляет начальную функциональную основу для ограниченного поиска, организации находок и анализа корреляций. До реализации автоматизированных, итеративных и масштабируемых исследований предстоит значительная работа.

## Текущие возможности

- Создание исследований и ручной запуск поиска по имени.
- Поиск в реализованных источниках: **GitHub и Wikidata**.
- Просмотр находок, URL, источников и индикаторов.
- Выявление корреляций по точным совпадениям нормализованных индикаторов.
- Создание кандидатных профилей, привязка находок и изучение связей на графе.
- Управление доступом через аутентифицированные учетные записи.

## Текущие ограничения и приоритеты развития

- Количество источников ограничено; поиск необходимо запускать вручную.
- Корреляция основана на детерминированных правилах и точных совпадениях; полноценный механизм разрешения идентичностей пока не реализован.
- Итеративное расширение поиска на основе новых находок и анализ больших объемов данных остаются задачами будущего развития.
- Возможности постоянного редактирования и удаления элементов графа требуют доработки.
- Платформа не использует ИИ/ML и нуждается в дополнительных тестах и формальной проверке.
- Приоритетами являются сокращение этих ограничений, рефакторинг кода и усиление безопасности.

## Установка

Требуются Git, Docker и Docker Compose.

```bash
git clone https://github.com/Starv1ng/PAPIRO.git
cd PAPIRO
cp .env.example .env
```

В Windows PowerShell вместо последней команды используйте `Copy-Item .env.example .env`.

Откройте `.env` и замените `AUTH_SECRET_KEY` собственным случайным секретом длиной не менее 32 символов. Сгенерировать его можно так:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Запустите сервисы:

```bash
docker compose up --build -d
docker compose ps
```

- Веб-интерфейс: http://127.0.0.1:8000/ui
- Документация API: http://127.0.0.1:8000/docs

Текущая конфигурация использует `network_mode: host`; в некоторых операционных системах и конфигурациях Docker Desktop могут потребоваться настройки сети.

## Первый запуск

1. Откройте интерфейс и создайте учетную запись **Investigator**. Пароль должен содержать не менее 12 символов.
2. Войдите в систему и создайте исследование.
3. Вручную запустите поиск по имени.
4. Изучите находки, источники, индикаторы и корреляции.
5. При необходимости организуйте находки в кандидатные профили и изучите связи на графе.

## Типы пользователей

- **Исследователь:** может проводить частные исследования или исследования для организации, в которую он входит.
- **Организация:** может управлять несколькими исследователями.
