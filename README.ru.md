# PAPIRO

**PAPIRO — разрабатываемая OSINT-платформа для исследования людей на основе общедоступной информации.** Долгосрочная цель проекта — автоматизировать максимально возможную часть процесса: собирать сведения из разных источников, обнаруживать и сопоставлять индикаторы, выявлять возможные идентичности и итеративно расширять исследование по мере появления новых данных, в том числе при обработке больших объемов информации.

Это целевое направление развития, а не описание текущего уровня автоматизации. Сегодня PAPIRO — начальная функциональная основа для ограниченного поиска, организации находок и анализа корреляций. До автоматизированного, итеративного и масштабируемого исследования предстоит значительная работа.

## Текущие возможности

- Создание исследований и ручной запуск поиска по имени.
- Поиск в реализованных источниках: **GitHub и Wikidata**.
- Просмотр находок, URL, источников и индикаторов.
- Выявление корреляций по точным совпадениям нормализованных индикаторов.
- Создание кандидатных профилей, привязка находок и изучение связей на графе.
- Работа через аутентифицированные учетные записи исследователей.

## Текущие ограничения

- Количество источников ограничено; поиск необходимо запускать вручную.
- Корреляция основана на детерминированных правилах и точных совпадениях; полноценный механизм разрешения идентичностей пока не реализован.
- Итеративное расширение поиска на основе новых находок и анализ больших объемов данных остаются задачами будущего развития.
- Возможности постоянного редактирования и удаления элементов графа требуют доработки.
- Платформа не использует ИИ/ML и нуждается в дополнительных тестах и формальной проверке.
- **Платформа не готова к промышленной эксплуатации**; не открывайте доступ из недоверенных сетей без проверки безопасности.

## Установка

Требуются Git, Docker и Docker Compose.

```bash
git clone https://github.com/Starv1ng/Kami-no-Eye.git
cd Kami-no-Eye
cp .env.example .env
```

В Windows PowerShell вместо последней команды используйте `Copy-Item .env.example .env`.

Откройте `.env` и замените `AUTH_SECRET_KEY` собственным случайным секретом длиной не менее 32 символов. Сгенерировать его можно так:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Запустите сервисы:

```bash
docker compose up --build -d
docker compose ps
```

- Веб-интерфейс: http://127.0.0.1:8000/ui
- Документация API: http://127.0.0.1:8000/docs

Текущая конфигурация использует `network_mode: host`; в некоторых операционных системах и конфигурациях Docker Desktop могут потребоваться настройки сети.

## Первый запуск

1. Откройте интерфейс и создайте учетную запись **Investigator**. Пароль должен содержать не менее 12 символов.
2. Войдите в систему и создайте исследование.
3. Вручную запустите поиск по имени.
4. Изучите находки, источники, индикаторы и корреляции.
5. При необходимости сгруппируйте находки в кандидатные профили и изучите связи на графе.

Чтобы создать учетную запись суперпользователя, выполните команду **до регистрации любой другой учетной записи**:

```bash
docker compose exec -it api python -m scripts.bootstrap_superuser
```

Скрипт дважды запрашивает адрес электронной почты и пароль; длина пароля должна быть не менее 12 символов. Команда работает только при отсутствии учетных записей.

## Тесты

```bash
docker compose run --rm api pytest -q
```

Запустите тесты в своей среде; README не гарантирует, что все тесты проходят в каждой версии.

## Ответственное использование

Проводите исследования только на законных основаниях, соблюдая право на частную жизнь и условия использования источников. Сохраняйте сведения о происхождении данных и проверяйте результаты: совпадение, кандидатный профиль или связь на графе сами по себе не подтверждают личность.

Если используется база данных от предыдущей версии, сначала создайте резервную копию и проверьте схему и инструкции по миграции. Не удаляйте Docker-том `pgdata`.
