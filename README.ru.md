# PAPIRO

**PAPIRO — разрабатываемая OSINT-платформа для исследования людей на основе общедоступной информации.** Долгосрочная цель проекта — автоматизировать максимально возможную часть процесса: собирать сведения из разных источников, обнаруживать и сопоставлять индикаторы, выявлять возможные идентичности и итеративно расширять исследования по мере появления новых данных, в том числе при работе с большими объёмами информации.

Это направление развития проекта, а не описание уровня автоматизации текущей версии. Сейчас PAPIRO предоставляет начальную функциональную основу для ограниченного поиска, организации находок и анализа корреляций. До реализации автоматизированных, итеративных и масштабируемых исследований предстоит значительная работа.

## Текущие возможности

- Создание исследований и ручной запуск поиска по имени.
- Поиск в реализованных источниках: **GitHub и Wikidata**.
- Просмотр находок вместе с их URL, источниками происхождения и индикаторами.
- Выявление корреляций по точным совпадениям нормализованных индикаторов.
- Создание кандидатных профилей, привязка находок и изучение связей на графе.
- Управление доступом через аутентифицированные учётные записи.

## Текущие ограничения и приоритеты развития

- Количество источников ограничено; поиск необходимо запускать вручную.
- Корреляция основана на детерминированных правилах и точных совпадениях; полноценный механизм разрешения идентичностей пока не реализован.
- Итеративное расширение поиска на основе новых находок и анализ больших объёмов данных ещё предстоит реализовать.
- Возможности постоянного редактирования и удаления элементов графа нуждаются в улучшении.
- Платформа не использует ИИ/ML и нуждается в дополнительных тестах и формальной проверке.
- Приоритетами являются устранение этих ограничений, рефакторинг кода и усиление безопасности.

## Установка

Требуются Git, Docker и Docker Compose.

```bash
git clone https://github.com/Starv1ng/PAPIRO.git PAPIRO
cd PAPIRO
cp .env.example .env
```

В Windows PowerShell вместо последней команды используйте `Copy-Item .env.example .env`.

Откройте `.env` и задайте криптографически стойкий случайный секрет для аутентификации длиной не менее 32 символов.

Запустите сервисы:

```bash
docker compose up --build -d
docker compose ps
```

- Веб-интерфейс: http://127.0.0.1:8000/ui
- Документация API: http://127.0.0.1:8000/docs

Текущая конфигурация использует `network_mode: host`; в некоторых операционных системах и конфигурациях Docker Desktop могут потребоваться настройки сети.

## Первый запуск

1. Откройте интерфейс и создайте учётную запись **Investigator**. Пароль должен содержать не менее 12 символов.
2. Войдите в систему и создайте исследование.
3. Вручную запустите поиск по имени.
4. Изучите находки, их источники, индикаторы и корреляции.
5. При необходимости организуйте находки в кандидатные профили и изучите связи на графе.

## Типы пользователей

- **Исследователь (Investigator):** может проводить частные исследования или исследования для организации, в которую он входит.
- **Организация (Entity):** может управлять несколькими исследователями.

Данные тестовых учётных записей указаны в испанском README. Эти учётные записи предназначены только для разработки: смените их пароли перед развёртыванием приложения и никогда не используйте их в рабочей среде.
