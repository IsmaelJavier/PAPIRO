# PAPIRO

PAPIRO — прототип OSINT-системы для сбора открытой информации, проверки совпадений и организации находок в кандидатные профили и граф исследования. **Совпадения являются подсказками, а не подтверждением личности.**

- [Español](README.md) · [English](README.en.md)

## Что уже реализовано

- Веб-интерфейс и API с аутентификацией и ролями.
- Поиск по имени в **GitHub и Wikidata**.
- Находки с URL источников и индикаторами, извлеченными из открытых данных.
- Детерминированная корреляция по точным совпадениям нормализованных индикаторов.
- Кандидатные профили, привязка находок и связи между профилями.
- Рабочее пространство исследования для проверки доказательств и просмотра графа.

## Установка

Требования: Git, Docker и Docker Compose. Текущая конфигурация Docker использует `network_mode: host`; для Docker Desktop и других сред могут потребоваться изменения сети.

```bash
git clone https://github.com/Starv1ng/Kami-no-Eye.git
cd Kami-no-Eye
git switch main
cp .env.example .env
```

Откройте `.env` и замените `AUTH_SECRET_KEY` собственным случайным секретом длиной не менее 32 символов. Сгенерировать его можно командой:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Запустите службы:

```bash
docker compose up --build -d
docker compose ps
```

Интерфейс: [http://127.0.0.1:8000/ui](http://127.0.0.1:8000/ui). Документация API: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

**База данных:** для новой установки со всеми функциями идентификации и ролей изучите и примените миграции из `migrations/` (002, 003, 004, 006 и 007 по порядку; миграция 004 запускается командой `docker compose exec api python -m scripts.apply_identity_migration`). Перед миграцией существующей базы сделайте резервную копию. Не удаляйте том `pgdata`.

После применения миграции 004 создайте первого администратора:

```bash
docker compose exec -it api python -m scripts.bootstrap_superuser
```

Скрипт запросит почту и пароль (не менее 12 символов). Он работает только если в базе еще нет учетных записей.

## Как проверить работу

1. Войдите в интерфейс.
2. Создайте исследование.
3. **Вручную запустите** поиск по имени: создание исследования не запускает поиск автоматически.
4. Просмотрите находки, источники, индикаторы и корреляции.
5. Создайте кандидатные профили, привяжите доказательства и изучите связи в графе.
6. Оценивайте совпадения осторожно: они не доказывают, что находки относятся к одному человеку.

Запуск автоматических тестов:

```bash
docker compose run --rm api pytest -q
```

PAPIRO продолжает разрабатываться, не использует ИИ/ML и не готов к промышленной эксплуатации. Используйте открытые данные законно и проверьте настройки безопасности перед открытием доступа из других сетей.
