# PAPIRO

PAPIRO — прототип OSINT-системы для сбора открытой информации, проверки совпадений и организации находок в кандидатные профили и граф исследования. **Совпадение — это подсказка, а не доказательство личности.**

- [Español](README.md) · [English](README.en.md)

## Что уже можно делать

- Создавать исследования и запускать поиск по имени.
- Искать в настроенных источниках: **GitHub и Wikidata**.
- Просматривать находки, источники, URL и индикаторы.
- Проверять детерминированные корреляции по точным совпадениям нормализованных индикаторов.
- Создавать кандидатные профили, привязывать доказательства и просматривать связи в графе.
- Работать через учетные записи исследователей с аутентификацией.

## Быстрая установка

Требования: Git, Docker и Docker Compose. Клонируйте репозиторий:

```bash
git clone https://github.com/Starv1ng/Kami-no-Eye.git
cd Kami-no-Eye
cp .env.example .env
```

В Windows PowerShell используйте вместо последней команды `Copy-Item .env.example .env`.

Откройте `.env` и замените `AUTH_SECRET_KEY` собственным случайным секретом длиной не менее 32 символов. Сгенерировать его можно так:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Запустите приложение:

```bash
docker compose up --build -d
docker compose ps
```

Откройте [веб-интерфейс](http://127.0.0.1:8000/ui). [Документация API](http://127.0.0.1:8000/docs) предназначена для технического использования.

**Нужно ли запускать миграции?**
- **Свежий клон с пустой базой данных:** нет. При запуске приложение создает таблицы текущих моделей.
- **Существующая база от предыдущей версии:** миграции могут понадобиться. Сначала сделайте резервную копию, затем проверьте инструкции миграций и реальную схему перед запуском скриптов из `migrations/`. Не удаляйте том `pgdata`.

Текущая конфигурация Docker использует `network_mode: host`; в некоторых ОС и конфигурациях Docker Desktop могут потребоваться изменения сети.

## Как пользоваться

1. Откройте интерфейс и выберите **Create account**, чтобы зарегистрироваться как **Investigator**. Пароль должен содержать не менее 12 символов.
2. Войдите в систему и создайте исследование.
3. Вручную запустите поиск по имени: создание исследования не запускает поиск автоматически.
4. Просмотрите находки, источники, индикаторы и корреляции.
5. Создайте кандидатные профили, привяжите доказательства и изучите связи в графе.
6. Оценивайте совпадения осторожно: они не являются окончательным доказательством личности.

Если нужна учетная запись суперпользователя для администрирования, создайте ее **до регистрации любых других учетных записей**:

```bash
docker compose exec -it api python -m scripts.bootstrap_superuser
```

Скрипт запросит почту и пароль дважды, требует пароль длиной не менее 12 символов и работает только при отсутствии других учетных записей.

## Тесты

```bash
docker compose run --rm api pytest -q
```

Запустите тесты в своей среде; README не утверждает, что все тесты проходят в текущем состоянии.

## Дальнейшая работа

- Итеративный поиск на основе новых индикаторов.
- Дополнительные источники и более широкий охват.
- Более полное редактирование и удаление элементов графа с сохранением изменений.
- Дополнительные тесты интерфейса, авторизации и установки.
- Формальная проверка метода и оценка платформы.

PAPIRO продолжает разрабатываться, не использует ИИ/ML и не готов к промышленной эксплуатации. Используйте открытые данные законно и проверьте безопасность перед открытием доступа из других сетей.
